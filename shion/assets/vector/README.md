# SHION original eco illustrations

Transparent PNG illustrations created specifically for the SHION mobile app. They use a character-led editorial illustration style and the SHION forest, leaf, cream, and terracotta palette.

- `ai_waste_scanner.png` — person scanning a bottle with a phone and detector frame; used in the dashboard and scan page.
- `community_waste_bank.png` — community recycling handoff; used in the deposit empty state.
- `eco_education.png` — reading beneath a tree with low-carbon living motifs; used in the SHION profile/about content.
- `plant_a_seedling.png` — caring for a new seedling; used in the profile welcome card.
- `reusable_lifestyle.png` — reusable bottle, tote, lunch box, and plant; used in the profile footer message.
- `waste_sorting_people.png` — two people sorting household waste; used in the profile activity card.
- `onboarding_hello.png` — a SHION neighbor greeting the user beside a fresh seedling; first onboarding screen.
- `onboarding_scan.png` — a volunteer scanning a bottle among leafy recycling motifs; second onboarding screen.
- `auth_login.png` — a reusable-lifestyle forest volunteer; sign-in screen.
- `auth_register.png` — neighbors sorting paper and bottles together; registration screen.
- `auth_password.png` — a terracotta lock wrapped in a growing vine; password setup screen.
- `auth_success.png` — a community celebrating a newly planted tree; account-created screen.

All six additions are original transparent PNG artwork with decorative botanical details composed into each scene. They are individually assigned to their onboarding or account step so the same hero illustration is not repeated across the flow.
